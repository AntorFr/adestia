# Fonts

All five families are under the SIL Open Font License 1.1, and shipped here as
the Latin subset Google Fonts serves (fetched 2026-10-01). They are bundled
rather than linked: an instance on the LAN should not need the internet to
look like itself.

| File | Family | Upstream |
|---|---|---|
| `CormorantGaramond.woff2`, `CormorantGaramond-Italic.woff2` | Cormorant Garamond (variable weight) | github.com/CatharsisFonts/Cormorant |
| `CormorantSC-600.woff2` | Cormorant SC | github.com/CatharsisFonts/Cormorant |
| `EBGaramond.woff2`, `EBGaramond-Italic.woff2` | EB Garamond (variable weight) | github.com/octaviopardo/EBGaramond12 |
| `CourierPrime.woff2` | Courier Prime | github.com/quoteunquoteapps/CourierPrime |
