# Notes:
# - The clipboard error on stderr disappears under a pty (OSC 52 works there),
#   so the code is not reliably on any one stream. Read both.
# - readline emits cursor escapes around the prompt even with NO_COLOR=1, and
#   the prompt has NO trailing newline: match on the accumulated buffer, never
#   line by line.
# - The container needs a CA store. node:22-slim has none (/etc/ssl/certs is
#   empty); node bundles its own roots, the Rust binary does not, and without
#   one every request fails as "Login failed: Error: request failed: builder
#   error" before it reaches the network.
