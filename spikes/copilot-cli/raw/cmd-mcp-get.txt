Usage: copilot mcp get [options] <name>

Show details for a specific MCP server.

Displays the full configuration including type, command/URL,
environment variables, headers, tools, and source information.

Arguments:
  name            Server name

Options:
  -h, --help      display help for command
  --json          Output as JSON
  --show-secrets  Show full environment variable and header values (masked by
                  default)

Examples:
  # Show server details
  $ copilot mcp get github

  # Show server details with secrets visible
  $ copilot mcp get github --show-secrets

  # Output as JSON
  $ copilot mcp get github --json

Learn More:
  Use `copilot <command> --help` for more information about a command.
