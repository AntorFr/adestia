# Inventaire — web-chat-charte

Statut : complet

Les six fichiers de cette grappe sont des tests vitest qui pilotent un navigateur. Les tests hors écran sont tous joués par la suite attestée : deux nouveaux, `packages/server/test/chat-charte-hors-ecran.test.ts` (un premier message dans une conversation neuve, la réponse à une question du moteur par `/api/permission`), et des tests déjà présents (`chat-hors-ecran.test.ts` : message tenu, arrêt, archivage ; `settings-turns.test.ts` : les tours simultanés ; `instructions.test.tsx`, `charter-menu.test.tsx`, `chat.test.tsx` : jsdom, trouvés en passant).

`charte-browser.ts` n'est pas un test : c'est l'aide commune de ces fichiers, elle n'a pas de ligne.

`À l'écran` dit `gardé` partout : le codeur ne modifie ni ne retire un test existant. L'allègement ou le retrait des lignes `scindé` revient au testeur, une fois le test hors écran rejoué. Rien n'est `effet` pur : chaque test garde au moins une assertion de rendu (la colonne dit laquelle).

Les 108 tests de `besoin-chargements-browser` vérifient la ligne de chargement, le message d'échec, le bouton Réessayer et leurs classes, dans deux langues et quatre habillages : c'est de l'affichage. Les mots d'un 401, 403 ou 404 viennent du module web, pas d'une règle du serveur.
